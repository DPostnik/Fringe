# Fringe — план

Статус: план, реализации нет. Дата: 2026-10-17.

Имена: шторка - **Fringe**; основное приложение - **Switchboard** (бывш. Context Desk, переименование: `codex-headroom-client/docs/switchboard-rename-plan.md`). Ниже «Context Desk» означает Switchboard; путь сокета зависит от того, будет ли переименована папка данных.

## 1. Что это

Отдельное нативное приложение macOS (SwiftUI/AppKit, без WebView/Electron), которое владеет шторкой над вырезом MacBook. При наведении шторка раскрывается в панель с вкладками:

1. **Агенты** — интеграция с Context Desk (статусы чатов, запросы агентов).
2. **Почта** — новые письма Gmail, открытие письма в браузере.
3. **Календарь** — ближайшие события.
4. **Скриншоты** — последние снимки экрана.
5. **Перевод** — переводчик в стиле Google Translate.

Context Desk перестаёт рисовать свою шторку, пока подключено это приложение, и становится поставщиком данных для вкладки «Агенты». Если приложение не запущено, Context Desk показывает свою шторку как сейчас.

## 2. Репозиторий и структура

Отдельный репозиторий `fringe` рядом с `codex-headroom-client`. SwiftPM.

```
fringe/
  Package.swift
  Sources/
    FringeApp/          # точка входа, AppDelegate, LSUIElement, настройки
    FringeNotch/        # панель над вырезом, hover, геометрия, анимации, очередь пиков
    FringeCore/         # тестируемая логика без UI: модели, политики, парсеры
    FringeAgents/       # вкладка «Агенты» + клиент канала к Context Desk
    FringeMail/         # IMAP IDLE, заголовки, ссылки на Gmail
    FringeCalendar/     # EventKit
    FringeScreenshots/  # NSMetadataQuery, миниатюры
    FringeTranslate/    # движки перевода
  Packages/
    FringeProtocol/     # общий пакет протокола; Context Desk подключает его с закреплённой версией
  Tests/
  scripts/build-app.sh, scripts/test.sh
  docs/improvements.md
```

- Bundle id: `local.daniil.fringe`. `LSUIElement` (без Dock), автозапуск через `SMAppService.mainApp`.
- Подпись тем же Apple Development сертификатом, что и Context Desk, чтобы разрешения macOS (Календарь, Рабочий стол) переживали пересборки.
- Минимальная macOS: 15 (нужно для Apple Translation как запасного движка).
- Интерфейс RU/EN через `L10n.text` по образцу Context Desk.
- Секреты (пароль приложения Gmail) только в Связке ключей.

## 4. Шторка (FringeNotch)

- Состояния: `hidden`, `compact`, `peek`, `expanded`, как в Context Desk.
- Компактная полоса: слева персонаж и счётчик агентов, справа счётчик непрочитанных писем.
- Открытая панель около 480×420: строка вкладок сверху, контент ниже. Последняя вкладка запоминается.
- **Клавиатура:** панель может стать key window. Пока фокус в поле ввода (перевод), шторка не закрывается при уходе курсора. Закрытие по Esc или по клику мимо.
- Горячая клавиша (настраиваемая) открывает шторку сразу на вкладке «Перевод».
- **Очередь событий** с приоритетами:
  1. запрос агента: открыть шторку, на 8 с переключить её на «Агенты», после ухода курсора вернуть прежнюю вкладку;
  2. агент закончил: пик «Готово · чат», 4 с;
  3. новое письмо: пик «отправитель · тема», 4–5 с.
  Низший приоритет ждёт, пока показывается высший.
- Свёрнутая шторка ничего не анимирует, кроме персонажа (Core Animation, остановлен в `hidden`). Контент вкладки создаётся только при её открытии.
- Звуки и системные уведомления включаются отдельными переключателями.

## 5. Вкладки

### 5.1 Агенты (Context Desk)

- Список до 8 активных чатов (работает, ждёт, есть непрочитанный результат) с активностью и длительностью, как сейчас.
- **Этап 1:** у запроса показываются причина и детали и кнопка «Ответить в чате», которая открывает чат в Context Desk.
- **Этап 2:** «Отклонить» / «Разрешить один раз» прямо в шторке, через `DeskModel.answer` на стороне Context Desk. Ответ отправляется ровно один раз. При обрыве связи с неизвестным результатом повтора нет, показывается «Проверь в чате».
- Context Desk не запущен: «Context Desk не запущен» и кнопка «Запустить». Остальные вкладки работают.

### 5.2 Почта (Gmail)

- **Транспорт:** IMAP IDLE к `imap.gmail.com:993`, одно соединение. IDLE обновляется каждые 10–25 мин. После сна или смены сети переподключение с паузами 2 с → 10 с → 1 мин → 5 мин.
- **Вход:** пароль приложения Google (нужна двухэтапная проверка), хранится в Связке ключей. *Допущение: перед реализацией проверить, что пароли приложений для IMAP доступны на аккаунте.* Если нет, вход через OAuth XOAUTH2 (свой проект Google Cloud в режиме production).
- **Только чтение:** заголовки и начало текста через `BODY.PEEK`, письма не помечаются прочитанными.
- **Фильтр по умолчанию:** «Входящие», основная категория (`X-GM-RAW "category:primary"`), без «Промоакций» и «Соцсетей».
- **Открытие:** `X-GM-MSGID` → hex → `https://mail.google.com/mail/?authuser=<адрес>#all/<hex>` в браузере по умолчанию (в настройках можно выбрать Chrome).
- Вкладка: последние 10–20 непрочитанных (отправитель, тема, время). По клику письмо открывается в браузере. Своего почтового клиента нет.
- Нагрузка: один простаивающий сокет, сотни байт раз в 10–25 мин.

### 5.3 Календарь

- **EventKit** (системный Календарь). Google-аккаунт добавлен в «Интернет-аккаунты» macOS. OAuth и опроса нет. Notion Calendar работает поверх Google, поэтому его события тоже видны.
- Обновление по `EKEventStoreChanged`, смене дня (`NSCalendarDayChanged`) и выходу из сна. Таймеров опроса нет.
- Список на 7 дней по группам «Сегодня», «Завтра», дальше даты: время, название, цвет календаря. Текущее событие подсвечено, у следующего отсчёт «через N мин» (обновляется раз в минуту, только когда вкладка видна).
- Кнопка «Подключиться», если в событии есть ссылка Meet/Zoom/Teams. По клику событие открывается в Календаре или по ссылке.
- Первая версия только для чтения.

### 5.4 Скриншоты

- Папка: `defaults read com.apple.screencapture location`, иначе `~/Desktop`.
- Поиск: `NSMetadataQuery` с `kMDItemIsScreenCapture == 1` в этой папке, обновляется сам. От имени файла и языка системы не зависит.
- Сетка последних 30 снимков, новые сверху, миниатюры через QuickLookThumbnailing с кэшем в памяти.
- Действия: перетаскивание в другое приложение, копирование в буфер, открыть, показать в Finder, удалить в Корзину.
- Один раз нужно разрешение на доступ к «Рабочему столу».

### 5.5 Перевод

- Сверху выбор языков «откуда → куда», кнопка обмена, «Автоопределение». Ниже поле ввода и результат с кнопкой «Копировать».
- Перевод через ~400 мс после остановки ввода. Последняя пара языков запоминается. При открытии можно подставлять текст из буфера (настройка, по умолчанию выключено).
- **Основной движок:** неофициальный Google Translate (`translate.googleapis.com/translate_a/single?client=gtx`). Бесплатно, без ключа, но может быть ограничен или изменён Google без предупреждения. Текст уходит в Google.
- **Запасной:** Apple Translation (офлайн), если Google не отвечает или пользователь выбрал его в настройках.
- Возможность на потом: официальный Cloud Translation API с ключом.

## 6. Связь с Context Desk (FringeProtocol)

- **Транспорт:** Unix-сокет `~/Library/Application Support/Context Desk/fringe.sock`, права `0600`. Сервер в Context Desk, клиент в Fringe.
- **Аутентификация:** Context Desk проверяет подпись подключившегося процесса по audit token: тот же Team ID и bundle id `local.daniil.fringe`. Иначе соединение закрывается.
- **Формат:** JSON-строки с полем `version`. При несовпадении версии или неизвестном типе сообщения соединение закрывается, ничего не угадывается.
- **Сообщения:**
  - CD → Fringe: `hello`, `snapshot` (чаты, сводка, запросы), `announce` (новый запрос / готово), `answerResult`.
  - Fringe → CD: `hello`, `openChat(id)`, `answer(requestID, response)` (этап 2).
- **Передача выреза:** при успешном `hello` Context Desk скрывает свою шторку. При разрыве соединения возвращает её. Двух шторок одновременно не бывает.
- Содержимое передаётся только по этому каналу, широковещательных уведомлений нет.

Изменения в Context Desk отдельной задачей в его репозитории: поставщик снимков на основе текущего `NotchIslandController.refresh()`, сервер сокета, передача выреза, подключение `FringeProtocol` с закреплённой версией. RU/EN, тесты, `docs/improvements.md` по правилам Context Desk.

## 8. Проверки

Юнит-тесты `FringeCore` и модулей:
- геометрия выреза и политика режимов, очередь пиков и приоритеты;
- фильтр скриншотов и сортировка;
- группировка событий по дням, отсчёт, поиск ссылок на созвоны;
- разбор ответа Google Translate (включая неожиданный формат → ошибка, а не мусор);
- разбор IMAP-ответов (EXISTS, FETCH, X-GM-MSGID), построение ссылки на письмо, политика переподключения;
- протокол: кодирование/декодирование, отказ на неизвестных сообщениях и чужой версии;
- сохранение настроек со значениями по умолчанию для старых версий.

Ручные проверки: hover и click-through, ввод текста без потери фокуса, пик при новом письме и при запросе агента одновременно, передача выреза при запуске/выходе любого из приложений, сон/пробуждение.
